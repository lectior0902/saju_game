# 사주 루트 설계서 (v0.7)

변경 이력
- v0.1: 사주 → 8유형, 루트와 노력 비용, 텍스트 프로토타입
- v0.2: 월·시 변주(160개 조합), 그래픽 웹 버전, 미니게임 3종, 엔딩 9종
- v0.3: 출발 환경(가정 형편 × 사는 곳) 추가, 모듈 분리와 테스트 33개, 배포 구조

## 1. 콘셉트

입력한 사주로 캐릭터에게 "타고난 경사(유리한 루트)"가 깔리고, 그 길을 따라가면 수월하다. 벗어나면 더 힘들지만 같은 길을 반복하면 길이 열린다. 여기에 사주와 별개로 "내가 고르지 않은 환경"이 더해져서, 같은 선택도 드는 비용이 달라진다.

핵심 메시지는 **경향일 뿐, 선택과 환경이 함께 결과를 만든다**다. 이 게임은 두 가지를 동시에 보여 주려고 한다. 하나는 출발선의 차이가 같은 노력의 비용을 바꾼다는 점이고, 다른 하나는 그 차이가 도달할 수 있는 곳을 막지는 않는다는 점이다.

## 2. 전체 구조

```
생년월일시 입력 + (선택) 가정 형편·사는 곳
  → 사주 8글자 → 오행 분포·일간 강약 → 8유형
  → 월지로 계절 변주, 시지로 시간대 변주
  → 환경: 선택한 값 또는 무작위
  → 유형 루트 2개 + 보조 분야 1개 + 계절 퍽 + 환경 효과 확정
  → 18~57세, 3년 단위 14턴. 분야를 고르면 미니게임을 플레이
  → 분야별 성취 합산 → 엔딩 9종 중 판정, 환경이 만든 차이 요약
```

## 3. 사주 → 유형 (src/core/saju.js)

1. 일간 지지율 ≥ 0.62 → 신강 독립가
2. 일간 지지율 ≤ 0.28 → 신약 협력가
3. 가장 큰 오행 비중 < 0.36 → 균형형 조정자
4. 그 외 → 가장 큰 오행에 따라 목 개척가 / 화 표현가 / 토 조율가 / 금 결단가 / 수 탐색가

| 유형 | 유리한 루트 | 기본 전성기 |
|---|---|---|
| 목 중심 개척가 | 사업, 창작 | 30~34세 |
| 화 중심 표현가 | 창작, 관계 | 27~31세 |
| 토 중심 조율가 | 조직, 관계 | 40~49세 |
| 금 중심 결단가 | 조직, 기술 | 36~41세 |
| 수 중심 탐색가 | 학문, 기술 | 45~49세 |
| 균형형 조정자 | 학문, 사업 | 40~45세 |
| 신약 협력가 | 관계, 학문 | 50~57세 |
| 신강 독립가 | 사업, 조직 | 30~39세 |

활동 분야는 6개: 학문 / 창작 / 사업 / 조직 / 관계 / 기술.

## 4. 월·시 변주 (160개 조합)

유형 8 × 계절 4 × 시간대 5(시를 모르는 경우 포함).

### 계절 (월지)
| 계절 | 전성기 이동 | 고유 퍽 |
|---|---|---|
| 봄 | −3세 | 개척 문턱 4 → 3 |
| 여름 | 0 | 성취 ×1.1, 행동마다 마음 소모 +1 |
| 가을 | +3세 | 좋은 사건 확률 +10%p |
| 겨울 | +6세 | 쉬면 마음이 +8 더 회복 |

전성기는 시작 21세 이상 51세 이하, 끝 60세 이하로 제한한다.

### 시간대 (시지)
유형 루트가 아닌 분야 하나가 보조 분야가 된다(효율 0.85배, 마음 소모 5, 미니게임 보통). 시를 모르면 없다.

| 시간대 | 보조 분야 후보(루트와 겹치면 다음 후보) |
|---|---|
| 심야형(자·축) | 학문, 창작, 기술 |
| 새벽형(인·묘·진) | 기술, 학문, 조직 |
| 한낮형(사·오·미) | 사업, 조직, 기술 |
| 저녁형(신·유·술·해) | 관계, 창작, 사업 |

후보를 3개씩 두는 이유: 2개이면 일부 유형의 루트와 둘 다 겹쳐 보조 분야가 비었다. 8유형 × 4시간대 전수 테스트가 이를 지킨다.

## 5. 출발 환경 (v0.3 신규)

사주는 "타고난 성향"이고, 환경은 "내가 고르지 않은 구조적 조건"이다. 두 축을 분리해서 둔다. 시작 화면에서 고르거나, 비워 두면 무작위로 정해진다. 엔딩에서 "환경만 바꿔서 다시"로 같은 사주를 다른 환경에서 걸어 볼 수 있다.

설계 원칙: **환경은 비용과 선택지로만 작동하고, 어떤 환경도 성취의 상한이나 엔딩 도달을 막지 않는다.** 환경을 능력 차이로 번역하지 않는다.

### 가정 형편
| 값 | 시작 마음 | 모든 행동 마음 소모 | 낯선 길·보조 추가 | 쉬기 회복 |
|---|---|---|---|---|
| 넉넉 | 85 | 0 | −1 | 보정 없음 |
| 보통 | 80 | 0 | 0 | 보정 없음 |
| 빠듯 | 75 | +1 | +1 | −4 |

### 사는 곳
| 값 | 매 턴 제시 분야 | 루트 분야가 선택지에 없을 확률 | 추가 요소 |
|---|---|---|---|
| 대도시권 | 5개 | 0 | 없음 |
| 중소도시 | 4개 | 0 | 없음 |
| 외곽·농촌 | 3개 | 25% | 지원 제도 |

### 지원 제도
불리한 쪽 환경 하나(빠듯, 외곽·농촌)당 매 턴 10% 확률로 지원 제도를 만나 마음 +10. 둘 다 해당하면 20%다. 구조적 불리함을 개인의 몫으로만 두지 않고, 제도가 완충하는 경로를 규칙에 넣었다.

### 환경이 만든 차이(엔딩 요약)
엔딩 화면에 세 가지를 보여 준다. 환경 때문에 더 쓴(또는 덜 쓴) 마음의 합계, 기본 4개 대비 제시 분야 수의 누적 차이와 루트 분야가 없던 해의 수, 지원 제도를 만난 횟수.

## 6. 게임 루프와 노력 비용 (src/core/rules.js)

| 항목 | 루트 / 열린 길 | 보조 | 낯선 길 |
|---|---|---|---|
| 기본 성취 | 10.0 | 8.5 | 6.5 |
| 마음 소모(기본) | 4 | 5 | 7 |
| 전성기(루트·열린 길) | ×1.3 | 없음 | 없음 |
| 미니게임 난이도 | 쉬움 | 보통 | 어려움 |
| 개척 포인트 | 없음 | 행동마다 +1 | 행동마다 +1 |
| 좋은 사건 확률 | 55% | 45% | 35% |

- 마음 소모는 여기에 계절(여름 +1)과 환경(빠듯 +1, 낯선 길·보조는 넉넉 −1 또는 빠듯 +1 추가)이 더해진다. 최소 1.
- 사건은 턴마다 50%. 좋으면 해당 분야 +6, 나쁘면 마음 −8.
- 개척 포인트가 4개(봄 3개)가 되면 길이 열려 루트와 같은 효율·난이도가 되고 +15.
- 마음 20 이하에서 행동하면 성취 절반, 번아웃 횟수 기록.
- 쉬기: 마음 +20(겨울 +8, 빠듯 −4). 매 턴 자연 회복 +3.

## 7. 미니게임

성과 등급(0~3)이 성취에 곱해진다: ×0.80 / ×1.00 / ×1.15 / ×1.30. 루트 밖일수록 어려워서 "더 많은 노력"을 손으로 느끼게 한다. 모든 게임에 건너뛰기(등급 1)가 있다.

| 게임 | 분야 | 쉬움 / 보통 / 어려움 | 등급 기준 |
|---|---|---|---|
| 타이밍 잡기 | 사업, 조직 | 구간 폭 28 / 21 / 15%, 속도 0.85 / 1.2 / 1.6 | 3회 중 맞힌 횟수 |
| 짝 맞추기 | 학문, 기술 | 3쌍·1.6초 / 4쌍·1.2초 / 5쌍·0.9초, 실수 5회까지 | 실수 1회 이하 3, 3회 이하 2, 완료 1, 실패 0 |
| 조각 모으기 | 창작, 관계 | 간격 760 / 660 / 560ms, 지속 1500 / 1150 / 900ms, 8초 | 3개 미만 0, 3개 1, 6개 2, 9개 3 |

## 9. 밸런스 시뮬레이션 (`npm run sim`, 미니게임 성과는 난이도별 확률분포 가정)

### 플레이 방식별 (환경 무작위, 각 3,000회)
| 방식 | 평균 총 성취 | 주요 엔딩 |
|---|---|---|
| 루트만 | 181 | 순풍 86%, 한 우물 8%, 두 길 6% |
| 루트 밖 한 분야를 끝까지 | 175 | 개척자 39%, 두 길 23%, 한 우물 19%, 거스름 14% |
| 루트 한 분야 집중 | 177 | 한 우물 61%, 순풍 38% |
| 초반 쉬다 후반 집중 | 151 | 순풍 53%, 늦게 핀 꽃 30% |
| 루트 밖만, 휴식 포함 | 152 | 거스름 72%, 잔잔 14%, 개척자 13% |
| 루트만, 쉬지 않음 | 183 | 순풍 82%, 한 우물 7%, 두 길 6%, 타버린 불꽃 5% |
| 루트 밖만, 쉬지 않음 | 156 | 거스름 60%, 타버린 불꽃 37% |
| 무작위 선택 | 123 | 잔잔 33%, 표류 28%, 순풍 16%, 개척자 14% |

### 환경별 평균 총 성취 (루트만 / 루트 밖 한 분야)
| 환경 | 루트만 | 루트 밖 | 환경이 만든 마음 비용 |
|---|---|---|---|
| 넉넉·대도시권 | 184 | 179 | 0 |
| 보통·중소도시 | 184 | 175 | 0 |
| 보통·외곽·농촌 | 176 | 175 | 0 |
| 빠듯·대도시권 | 180 | 171 | +15.6 |
| 빠듯·외곽·농촌 | 172 | 171 | +18.8 |

가장 유리한 환경과 가장 불리한 환경의 평균 격차는 루트 플레이에서 약 6~7%다. 테스트는 이 격차가 3% 초과 20% 미만에 있어야 통과한다(체감은 되되 노력이 무의미해지지는 않도록). 가장 불리한 환경에서도 루트 플레이의 평균은 150을 넘고 순풍·한 우물이 절반 이상이다.

### 조정 이력
- 마음 소모를 줄이고 회복을 늘림(모든 플레이가 번아웃으로 끝나던 문제)
- 한 우물 기준 60% → 72%
- 표류하는 삶을 "열지 못한 낯선 길"에서 "최고 분야 40 미만"으로 변경(도달 불가였음)
- 타버린 불꽃 5회 → 3회
- 환경 효과 보강: 처음에는 환경이 거의 영향이 없었다. 루트만 따르는 플레이는 마음이 거의 닳지 않아 "빠듯"의 비용이 걸리지 않았고, "외곽"은 루트 분야가 늘 보장돼 차이가 없었다. 그래서 빠듯은 모든 행동의 소모를 올리고, 외곽은 4번에 1번 루트 분야를 선택지에서 뺐다.

## 9-1. 마을 모드 (v0.4)

규칙은 그대로이고 선택 화면만 바뀐다. 17×12 칸 지도에 건물 6채(분야)와 쉼터. 올해 제안되지 않은 분야의 건물은 닫혀 있고, 열린 건물에는 순풍/열린 길/보조/낯선 길 표시가 붙는다. 문 앞에 서면 확인 창 → 기존 미니게임. 해가 바뀌면 출발점으로 돌아온다. 마을 로직은 `src/ui/village-logic.js`(테스트 9개), 그림은 `src/ui/village.js`.
화면은 위에 마을, 아래에 사주 풀이 패널이다. 건물은 분야별로 모양이 다르다(학문 도서관, 창작 아틀리에, 사업 상점, 조직 관공서, 관계 모임 카페, 기술 공방). 순풍·열린 길 건물 문 앞은 반짝이고, 해가 바뀔 때마다 계절 분위기(봄 꽃잎, 여름, 가을 낙엽, 겨울 눈)가 바뀐다. 마을 사람 3명이 길을 오간다.
이후 확장: 건물 안 장면, NPC 대화로 이벤트 연출, 계절에 따른 타일 색, 직접 그린 타일셋으로 교체.

## 9-2. 사건·퀘스트·분야별 미니게임 (v0.5)

**미니게임 6종**: 학문 서가 짝 맞추기, 창작 영감 조각 모으기, 사업 거래 타이밍, 조직 서류 분류(10장), 관계 마음 맞추기(순서 따라 하기, 3판), 기술 정밀 조립(누르고 있다 놓기, 3회). 모두 성과 0~3등급을 돌려주고 난이도는 기존처럼 루트 0 / 보조 1 / 그 밖 2다. 건물 안 삽화는 분야마다 다르다(`interior.js`).

**마을 사건**: 해마다 1건(`events.js`, 15종). 선택지는 세 개이고 세 번째는 항상 아무 일도 없는 "지나친다"다. 보상은 작게 잡았다. 시뮬레이션(route/rebel, 각 2000판): 사건 없음 180/153, 무작위 선택 193/168, 최선 선택 206/187. 즉 최선으로 챙겨도 +14%, 루트 밖 플레이는 개척 포인트 덕에 +22%. 엔딩 9개는 사건이 있어도 모두 도달 가능(테스트).

**낯선 길 퀘스트**(`quests.js`): 루트가 아닌 분야(보조 포함) 행동마다 개척 포인트가 오르며 이야기가 한 단계 나아간다. 0등급이어도 이야기는 이어지고(실패 문장), 굳은살이 +1(상한 2)이 되어 다음 행동의 마음 비용이 −1(한 번에 1 소모)이다. 개척 포인트와 같은 숫자를 써서 기존 열림 규칙(4번, 봄 3번)과 밸런스는 그대로다.

## 9-3. 엔딩 화면과 인생 풀이 (v0.6)

한 해마다 기록을 남긴다(`ch.history`: 나이, 분야, 모드, 등급, 성취, 전성기·지침·열림 여부). `reading.js`가 이 기록으로 초년운(18~29세), 중년운(30~44세), 말년운(45~57세)을 만든다. 시기마다 태그(상승·순탄·오르막·고비·쉼)와 문장 조각(주된 분야, 순풍/낯선 길 비율, 열린 길, 전성기, 지침, 쉼, 실패해도 이어진 이야기)을 조건에 따라 조합한다. 엔딩 9종마다 한 줄 풀이와 조언이 있다. 그림은 96×64 칸 도트를 코드로 찍어 CSS로 키운 것이다.
조작: 마을에서 화면이나 방향 버튼을 누르고 있으면 계속 걷는다.

## 9-4. 풀이 문장 다양화 (v0.7)

문장은 `reading-data.js`의 풀(분야·상황별로 3~5개 표현)에서 고른다. 고르는 값은 판의 기록으로 정해서(시드) 같은 판은 늘 같은 풀이가 나오고 다른 판은 표현이 갈린다. 추가한 풀이 요소: 시기별 사자성어(순풍만범, 우공이산, 칠전팔기, 과유불급, 유유자적, 동분서주, 일취월장, 수처작주, 대기만성, 안분지족), 세운(가장 빛난 해, 길이 열린 해, 가장 버거웠던 해, 쉬어 간 해, 운에 맡긴 해), 일간 이미지(갑목~계수 10종) 풀이, 기운 풀이(분야를 오행에 대응: 사업 목, 창작 화, 관계 토, 조직·기술 금, 학문 수. 금형 루트가 조직·기술을 함께 갖는 기존 설정을 따름). 부족한 기운에는 어울리는 분야와 방위·색·계절을 붙인다. 이 대응은 게임용 해석이다.

## 10. 알려진 한계

- 절기 경계는 매년 같은 날짜로 근사했다. 절기 당일 전후 하루는 틀릴 수 있다.
- 자시(23시) 이후 출생의 일주 처리는 단순화했다.
- 유형별 루트·전성기·계절 퍽·시간대 보조 분야·환경 효과는 게임용 가정이다. 명리학이나 사회과학의 정설이 아니다. 대운·십성·용신은 쓰지 않았다.
- 환경 효과는 비용과 선택지로 단순화한 모형이다. 실제 불평등은 성과(수익률) 격차, 정보와 네트워크, 누적 효과를 포함하는데 이 모형은 그중 일부만 다룬다.
- 미니게임은 jsdom으로 조작 흐름만 검증했다. 속도, 터치 영역, 난이도는 실제 기기에서 조정이 필요하다.
- 시뮬레이션은 미니게임 성과를 확률분포로 가정한 값이다.
